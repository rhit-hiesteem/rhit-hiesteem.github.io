Fitness Tracker

Technologies: Java, SQL

I developed a Fitness Tracker application for my Database Systems course that allows users to manage their workouts and track their fitness information. Users can create and view workouts, record exercises, and keep track of important fitness data over time. The project was designed to provide an organized way for users to manage their workout history and monitor their progress.

Platformer Game

Technologies: Java

I developed a 2D platformer game where players traverse challenging levels while avoiding and defeating enemies. Players collect coins throughout each level and gather resources to build a bonfire, which serves as the objective for completing the level. The game combines exploration, combat, and resource collection to create an engaging gameplay experience.

Verb Vault

Technologies: HTML, CSS, PHP, JavaScript

I developed a library application that allows users to browse a collection of books and manage their personal library. Users can search for and add books to their collection by ISBN, mark books as favorites, and check books out or return them. The application provides an organized way for users to discover, manage, and keep track of their books.
